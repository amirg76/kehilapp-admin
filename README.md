# Kehilapp — Admin Dashboard

A **React + TypeScript** admin dashboard for **Kehilapp**, a platform built after October 7th to organize the daily flood of WhatsApp messages for an evacuated kibbutz community. This dashboard lets administrators manage content, categories and entries.

Built as a pilot with a small volunteer team, in collaboration with the AppleSeeds (Tapuach) nonprofit. Covered by *Yediot HaNegev*.

> Part of a 3-tier system: [Backend API](https://github.com/amirg76/kehilapp-backend) · [User App](https://github.com/amirg76/kehilapp-front) · **Admin Dashboard (this repo)**

### Tech Stack
- **Framework:** React + TypeScript (Vite)
- **UI:** Material UI (MUI) · MUI X Data Grid
- **Data:** React Query
- **Charts:** Recharts
- **Styling:** Sass

### Status
Pilot — not taken to production.
